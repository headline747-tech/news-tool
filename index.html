    Blogger সংযোগ

    1. console.cloud.google.com-এ প্রজেক্ট খুলে Blogger API v3 চালু করুন।
    2. OAuth consent screen-এ Test users-এ আপনার Gmail যোগ করুন।
    3. Credentials → OAuth client ID (Web application) → Authorized JavaScript origins-এ যে ঠিকানা থেকে ফাইল খুলবেন সেটি দিন (যেমন http://localhost:8000)।
    4. file:// থেকে খুললে Google লগইন চলবে না; হোস্ট করুন বা localhost সার্ভারে চালান।
